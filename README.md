🚌 **Python Project: Bus Pass Reservation System**

I’m excited to share one of my recent Python projects — a **Bus Pass Reservation System** built using **Python, Object-Oriented Programming (OOP), and Streamlit**.

🎯 **Project Objective**

The goal of this project is to create a simple and user-friendly system for managing bus passes digitally instead of handling the process manually.

🔹 **Key Features**

✅ Reserve a new bus pass
✅ Enter passenger details such as name, age, source and destination
✅ Choose Monthly, Quarterly, or Yearly pass
✅ Automatic pass fee calculation
✅ View all reserved bus passes
✅ Track pass status
✅ Renew an existing pass
✅ Cancel a bus pass
✅ Dashboard showing Total, Active, Renewed and Cancelled passes
✅ Interactive and user-friendly Streamlit interface

💻 **Technologies Used**

• Python
• Object-Oriented Programming (OOP)
• Streamlit
• HTML/CSS for interface customization
• Python Session State for maintaining application data

🧠 **OOP Concepts Applied**

The project uses classes such as `BusPass` and `BusPassReservation` to organize the application logic. The `BusPass` class handles passenger details, pass type, fee and status, while the reservation class manages the collection of passes.

📊 **What I Learned**

Through this project, I improved my understanding of:

• Classes and objects
• Constructors
• Methods
• Conditional statements
• Lists and loops
• Session state management
• Streamlit UI development
• Basic application design
• Converting Python logic into an interactive web application

🚀 **Why this project matters**

This project helped me understand how programming concepts can be combined to build a practical application. It also gave me hands-on experience in developing a simple web-based application using Python.

I’m looking forward to improving this project further by adding features such as **database connectivity, user authentication, online payment integration, QR-code based passes, and downloadable digital bus passes.**
